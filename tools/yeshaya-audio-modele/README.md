# yeshaya-audio

Fichiers MP3 de l'application **Yeshaya**, servis gratuitement par GitHub Pages.
Ce dépôt doit rester **public** (GitHub Pages est gratuit pour les dépôts publics).

Adresse des fichiers : `https://berthautk.github.io/yeshaya-audio/<dossier>/<fichier>.mp3`

## Règles
- **MP3 mono, 48 à 64 kbit/s** : environ 0,4 Mo par minute, ce qui ménage les forfaits de données.
- **Moins de 100 Mo par fichier** (limite de GitHub). Un enseignement d'une heure en 48 kbit/s pèse environ 22 Mo.
- **Noms de fichiers** en minuscules, sans accents ni espaces : `la-puissance-de-la-priere.mp3`.
- **Uniquement des audios dont l'auteur a donné son accord.**

## Dossiers
| Dossier | Contenu |
|---|---|
| `enseignements/` | Enseignements d'édification |
| `prieres/` | Enseignements et sujets de prière |
| `meditations/` | Méditations du matin |
| `dialogues/` | Dialogues d'évangélisation |
| `evangelisation/` | Motivation, formation, objections |
| `nouveau-converti/` | Parcours de 30 jours |

Le fichier `.nojekyll` évite que GitHub Pages ignore certains fichiers : ne le supprimez pas.
