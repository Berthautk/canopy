# Tests des veilles de prière

    npm run veilles

Vérifient, sans navigateur : le thème de chaque jour (lundi = jour 1, dimanche = jour 7), les trois
tailles (court < normal < complet), la série de jours de suite, le psaume d'adoration de chaque jour et
de chaque veille, et le compteur « prier ensemble » (qui n'expose que trois totaux).
